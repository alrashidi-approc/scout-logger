# Architecture Decision Records

When `/grill-with-docs` (or a design discussion) locks a non-obvious decision, add a short ADR here.

## Naming

`NNNN-short-slug.md` — zero-padded number, next free integer.

## Template

```markdown
# NNNN. Title

## Status
Accepted | Superseded by NNNN

## Context
Why this came up (1–3 sentences).

## Decision
What we chose.

## Consequences
What becomes easier / harder; follow-ups.
```
